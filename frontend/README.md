# 🎨 Reveil Frontend

The  is the **Reveil Frontend** .  
It handles user authentication, API requests, and provides an intuitive UI for users to interact with the FastAPI backend.

| Category | Technology |
|:----------|:------------|
| Framework | React (Vite) |

| HTTP Client | Axios |
| Auth | JWT Tokens |
| Icons | Lucide React, React Icons |
